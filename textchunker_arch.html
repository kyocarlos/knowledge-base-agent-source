文件分塊器 - 將長文件分割成小區塊，保留語意完整性

三種分塊方法
H
chunk_by_headers()
按 Markdown 標題（##, ###）分割
# 用正規表達式找出所有標題 header_pattern = r'(^#{1,6}\s+.+)$' parts = re.split(header_pattern, content, flags=re.MULTILINE)
P
chunk_by_paragraphs()
按空行分割成段落
# 按空行分割 paragraphs = re.split(r'\n\s*\n', content)
✨
chunk_markdown()
自動選擇：有大標題用 headers，否則用 paragraphs
has_headers = bool(re.search(r'^#{1,6}\s', content, re.MULTILINE)) if has_headers: return chunk_by_headers() # 有標題 else: return chunk_by_paragraphs() # 無標題
