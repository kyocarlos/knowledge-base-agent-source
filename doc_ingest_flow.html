📄 文件攝入流程架構圖

Document Ingestion Pipeline Architecture

1
📤 文件上傳 不用 LLM
使用者上傳文件，支援 PDF、Word、Excel、PowerPoint、Markdown 等格式
2
🔄 MarkItDown 轉換 不用 LLM
將各種格式轉換為 Markdown 純文字，保留標題結構（## 標題）
3
✂️ TextChunker 分割 不用 LLM
按 ## 標題將文件分割成多個 TextUnit（文字區塊）
輸出：3 個 TextUnit
4
💾 存入 Neo4j 不用 LLM
建立 Document 節點 → 建立 TextUnit 節點 → 建立 CONTAINS 關係
🤖
🧠 LLM 萃取實體 使用 LLM
叫用 gemma4:e4b 模型，分析 .md 內容找出：
• Entity：設備名稱、人名、機構、事件等
• RELATES_TO：實體之間的關係

輸出：45 個 Entity，27 條 RELATES_TO 關係
6
🔢 BGE 產生向量 不用 LLM
使用 BAAI/bge-base-zh-v1.5 模型將 TextUnit 轉為 768 維向量
7
📍 存入 QDrant 不用 LLM
將向量與 TextUnit 內容存入 QDrant 向量資料庫，支援語意相似度搜尋
