## Phase 2（10～14 週）

- WiFi Benchmark 基礎：轉檔、資料整理、圖表與 AI KM 查詢入口。
- File Type Detector、Vision／OCR／Image、Table／Excel Pipeline。
- 依 Patty 的 Knowledge Package Schema 實作 Model／Validator／Serializer。
- 主實作 Schema Validator；依 Patty 的 Routing／DB 邊界實作 Router／Adapter。
- 依正式 Ontology／Payload 實作 Entity Normalize、Neo4j MERGE、Qdrant Index／Rebuild／Filter。
- 完成 Document → Package → Validation → Routing → DB 的可重跑端到端 Pipeline。

## Phase 3～5

- Phase 3：Intent Classifier、Fast／Agentic Selector、Planner、Router、Registry／Executor、Evidence Validator、Context／Citation Builder。
- Phase 4：Root Cause、Benchmark Analysis、Similar Case／Recommendation、AI Report Review／Summary、Evaluation Runner。
- Phase 5：Orchestration、Multi-Agent、Predictive／Trend、Auto Benchmark／Notification；資料不足或前階段未成熟時不得啟動。

## 禁止越界

1. 不修改 CSIT 內部程式、DB Schema、Workflow 或既有商業邏輯。
2. 不直連 CSIT DB，也不在 AI KM 建立另一套正式 Booking／Request／Approval 狀態。
3. 不自行變更 Knowledge Package、Payload、Ontology、Tool Contract 或資料口徑。
4. 不讓 Prompt、前端或 LLM 取代後端 ACL、人工核准或白名單 Tool。
5. 不以 HTTP 200 或 Demo 取代資料正確性、版本、權限、重跑與失敗模式驗收。
