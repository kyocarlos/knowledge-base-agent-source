## 與目前進度的關係

- WP0：保留既有 FastAPI contract、response/error/trace、legacy compatibility 與測試基線；原始 FastAPI 規格現可直接核對。
- WP1：保留既有 Docker/Redis/Celery job config、queue/retry、trace、idempotency 與 worker reliability；原始部署規格現可直接核對。
- WP2～WP13：本週仍維持尚未開始，不因原始設計文件已納入 Git 而計入程式進度。
- 原始文件的存在是「規劃與驗收依據已保存」，不是「對應 WP 已完成」。
