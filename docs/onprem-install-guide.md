# B2B / On-Prem 安裝手冊

這份說明是給不熟悉系統的人看的。  
你不需要先理解程式碼，只要照著順序做即可。

## 這份安裝包是什麼

你會拿到一個安裝包，例如：

- `knowledge-base-onprem-20260611_094458-75f3ba30.tar.gz`

這個檔案裡已經包含：

- 系統本體
- 安裝程式 `install.sh`
- 前端頁面
- Docker 設定
- 需要的設定範本

所以安裝時，不需要再另外下載專案原始碼。

## 你要先準備什麼

請先確認目標電腦有下面幾項：

- `Docker`
- `Docker Compose`
- `tar`
- `curl`
- `openssl`

如果不確定有沒有裝好，直接執行安裝包時，系統會先幫你檢查。

## 建議安裝環境

這套安裝包以 Linux on-prem 環境為主。  
如果你是在 Windows 上安裝，通常會建議先確認：

- 有沒有安裝 Docker
- 有沒有可用的 bash 環境
- 是否由 IT 部門提供安裝方式

如果你不確定，直接把這份手冊交給 IT 或代管人員照做最穩定。

## 你需要帶去另一台電腦的檔案

最少只需要這一個檔案：

- `knowledge-base-onprem-20260611_094458-75f3ba30.tar.gz`

如果你要保留完整驗證，也可以一起帶：

- `knowledge-base-onprem-20260611_094458-75f3ba30.tar.gz.sha256`

如果要搬資料，另外還需要：

- 你的資料 bundle
- 你的 OpenClaw bundle

## 安裝前先做的事

1. 把安裝包複製到目標電腦。
2. 放到一個你找得到的位置，例如桌面、下載資料夾，或某個專案資料夾。
3. 確認目標電腦已安裝 Docker，並且 Docker 已啟動。

## 安裝步驟

### 步驟 1：解壓安裝包

把 `tar.gz` 檔解壓縮。

如果你是 Linux / macOS，通常可用：

```bash
tar -xzf knowledge-base-onprem-20260611_094458-75f3ba30.tar.gz
```

解壓後會看到一個資料夾，裡面有 `install.sh`。

### 步驟 2：進入解壓後的資料夾

```bash
cd knowledge-base-onprem-20260611_094458-75f3ba30
```

### 步驟 3：先做檢查，不安裝

如果你想先確認環境夠不夠，不要正式安裝，可以先跑：

```bash
./install.sh --check-only
```

這個模式只會檢查，不會安裝，不會改動檔案。

如果畫面顯示缺少元件，就先把那些元件補齊，再繼續下一步。

### 步驟 4：正式開始安裝

直接執行：

```bash
./install.sh
```

接下來會一個一個問你問題。  
你可以直接按 Enter 使用預設值。

## 安裝時會問你什麼

### 1. 安裝路徑

這是系統要裝在哪裡。  
如果你不懂，直接按 Enter 使用預設路徑即可。

### 2. Compose project name

這是系統內部使用的名稱。  
如果你不懂，直接按 Enter 使用預設值。

### 3. HTTPS port

這是你之後要開啟網站時使用的連接埠。  
如果系統顯示預設值，通常直接按 Enter 就好。

### 4. Neo4j 密碼

這是資料庫密碼。  
如果你不是 IT 人員，通常直接使用系統給的預設值即可。  
如果你自己設定，請務必記下來，不要忘記。

### 5. Ollama endpoint

這是模型服務位置。  
如果你不確定，先用預設值，不要自行亂改。

### 6. OpenClaw gateway

這是系統和外部服務溝通時用的設定。  
如果你不懂，按 Enter 使用預設值。

### 7. 是否匯入資料 bundle

如果你有另外準備資料包，這裡就選擇匯入。  
如果沒有，就直接跳過。

### 8. 是否匯入 OpenClaw bundle

如果你有 OpenClaw 的附加設定包，就匯入。  
如果沒有，就跳過。

## 如果你沒有網路

如果目標電腦不能上網，請使用：

```bash
./install.sh --offline
```

這個模式的意思是：

- 不會嘗試上網補裝套件
- 如果必要元件缺少，會直接停止
- 適合內網、封閉網路、或管制環境

## 如果你只是想先確認能不能安裝

請使用：

```bash
./install.sh --check-only
```

這只會檢查環境，不會真的安裝。

## 安裝完成後你會看到什麼

安裝完成後，畫面會顯示：

- 安裝版本
- 安裝路徑
- 專案名稱
- Web port
- 安裝模式

通常還會做一次健康檢查。  
如果看到 `Health check OK`，表示系統大致可正常運作。

## 安裝完要怎麼開啟

安裝完成後，請依畫面顯示的 Web port 開啟網站。  
例如如果顯示 `18443`，就用瀏覽器打開對應網址。

如果你不確定網址是什麼，請看安裝結束時的畫面，裡面會有 `Web port`。

## 常見問題

### 1. 它說缺少 Docker

代表這台電腦還沒有裝好 Docker，或 Docker 沒有啟動。  
請先請 IT 安裝並啟動 Docker，再重新執行安裝包。

### 2. 它說缺少 Docker Compose

代表 Docker 的 compose 功能還沒準備好。  
請先補齊 Docker Compose，再重新執行。

### 3. 它說缺少 curl / openssl / tar

這些是系統安裝時需要的小工具。  
如果你不懂怎麼補，請交給 IT 處理。

### 4. 它說 Docker is installed but not running

代表 Docker 已經裝了，但目前沒開啟。  
請先把 Docker 啟動，再重新執行安裝包。

### 5. 安裝中途停住

先不要關掉視窗。  
請先看畫面最後一行寫什麼，通常會告訴你缺什麼。

如果真的看不懂，把最後 20 行畫面複製給 IT 或支援人員。

## 升級舊版本

如果這台電腦以前已經安裝過，新的安裝包通常會自動走升級流程。  
你只需要重新執行 `install.sh`，系統會盡量保留：

- 使用者資料
- 部分設定
- OpenClaw 相關 overlay

## 你不需要做的事

- 不需要自己改程式碼
- 不需要自己 build
- 不需要自己安裝 Python / npm
- 不需要自己從 GitHub clone

## 給 IT 或代管人員的提醒

如果你是負責幫別人安裝的人，請先確認：

- 目標機器有 Docker
- 目標機器有網路，或已準備離線模式所需內容
- 資料 bundle 是否已另外準備
- 是否要先跑 `--check-only`

如果要完全離線，請先確認所有必要元件都已到位，再執行 `--offline`。
