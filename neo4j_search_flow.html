Step 1

📥 使用者輸入搜尋問題

「列出所有NR基站設備」

↓
階段二：關鍵字萃取
Step 2

🔎 extract_keywords()

使用 LLM 萃取關鍵字

keywords = ["NR", "基站", "設備"]
↓
階段三：Cypher 指令生成
Step 3

⚙️ 組裝 Cypher 查詢

Basic Mode 關鍵字搜尋

MATCH (d:Document) WHERE d.content CONTAINS 'NR' OR d.name CONTAINS 'NR' OR d.content CONTAINS '基站' OR d.name CONTAINS '基站' OR d.content CONTAINS '設備' OR d.name CONTAINS '設備' RETURN d.name, d.content LIMIT 10
↓
階段四：發送到 Neo4j
Step 4

📡 session.run(cypher)

使用 Neo4j Python Driver 發送 Cypher 指令

result = session.run( "MATCH (d:Document) WHERE ...", limit=10 )
↓
階段五：Neo4j 執行引擎

① 解析 Cypher

解析指令語法與語意

② 使用索引加速

🔬 Deep Mode 額外流程
Deep Mode

圖遍歷 + 關係擴展

MATCH (e:Entity) WHERE e.name CONTAINS 'NR' WITH e LIMIT 5 OPTIONAL MATCH (e)-[r]-(related) RETURN e.name, e.type, collect(related.name) as connections

Deep Mode 會擴展到 Entity 的鄰居節點，
而 Basic Mode 只返回直接匹配的 Document

標準流程
Cypher 查詢生成
系統輸出
